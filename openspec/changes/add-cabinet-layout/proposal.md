# Proposal

## Why
Пустой корневой экран нуждается в визуальной основе личного кабинета, связанной с именем World of Leprechaun.

## What Changes
- Добавить адаптивную шапку с брендом и навигацией, мобильное меню.
- Создать основной layout с областью содержимого и подвалом.
- Оформить стартовый экран и тему MUI в зелёных и золотых оттенках.

## Capabilities
### New Capabilities
- `cabinet-layout`: навигация и адаптивный каркас кабинета.
### Modified Capabilities
Нет опубликованных спецификаций; новое оформление заменяет временную пустую страницу bootstrap-frontend.

## Impact
app/theme, app/router, widgets/site-header, widgets/cabinet-layout, pages/home, shared/ui. API, авторизация и получение конфигов вне объёма.
