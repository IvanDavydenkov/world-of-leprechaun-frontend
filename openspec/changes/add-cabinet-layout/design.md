# Design

## Context
Основа приложения на React/MUI уже работает. Корневой маршрут временно пустой.

## Goals / Non-Goals
Цель — шапка и переиспользуемый каркас. Реальные данные аккаунта, endpoints, оплата и загрузка не реализуются.

## Decisions
- Mobile-first: компактный бренд и кнопка меню; на desktop горизонтальная навигация, более широкие отступы и две колонки содержимого.
- app компонует независимые widgets шапки и layout через children/Outlet; widgets не импортируют друг друга. pages/home содержит только содержимое страницы.
- shared/ui содержит переиспользуемый векторный знак клевера. Тема MUI задаёт зелёные поверхности, золотой акцент, типографику и фокус.
- Навигация использует существующий маршрут и якоря существующих секций. Меню — MUI Drawer с локальным состоянием, закрытием после выбора и доступными подписями.
- Начальный экран обозначает место будущих конфигураций без фиктивного статуса пользователя и доступных для скачивания файлов.

## Risks / Trade-offs
Нет API → экран показывает нейтральную заглушку, а не утверждает, что у пользователя нет конфигов. Фирменный стиль выведен из домена и может быть изменён позже.
