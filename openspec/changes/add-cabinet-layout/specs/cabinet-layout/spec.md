# Spec Delta

## Purpose
Предоставить пользователю узнаваемый адаптивный каркас кабинета World of Leprechaun с удобной навигацией на телефоне и компьютере.

## ADDED Requirements

### Requirement: Адаптивный каркас
Интерфейс SHALL показывать бренд, основную навигацию, область содержимого и подвал, сохраняя читаемость и доступность на мобильных и desktop-экранах.

#### Scenario: Мобильный экран
- **GIVEN** пользователь открывает кабинет на телефоне
- **WHEN** он нажимает кнопку меню
- **THEN** открывается меню навигации, которое можно закрыть или выбрать пункт

#### Scenario: Desktop
- **WHEN** пользователь открывает кабинет на широком экране
- **THEN** навигация доступна в шапке, а содержимое ограничено по ширине и адаптировано к экрану

### Requirement: Честное начальное состояние
Экран SHALL обозначать область будущих конфигураций без фиктивных данных аккаунта, статуса подключения и кнопок скачивания несуществующих файлов.

#### Scenario: Открытие кабинета
- **WHEN** пользователь открывает `/`
- **THEN** видит заголовок кабинета и область конфигураций без демонстрационных VPN-конфигов
