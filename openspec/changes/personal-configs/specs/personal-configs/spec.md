# Spec Delta

## Purpose
Дать авторизованному пользователю доступ к собственным активным VPN-конфигам и скачиванию текущего файла с главной страницы.

## ADDED Requirements

### Requirement: Собственный список
Главная SHALL получать список через RTK Query из /me/configs без идентификатора владельца, показывать имя, версию, дату и доступность файла на мобильных и desktop-экранах.

#### Scenario: Список
- **WHEN** API возвращает active-конфиги
- **THEN** пользователь видит записи и кнопки скачивания доступных файлов

#### Scenario: Пустой ответ
- **WHEN** сервер возвращает []
- **THEN** отображается объяснение отсутствия активных конфигов

#### Scenario: Ошибка списка
- **WHEN** запрос завершается ошибкой
- **THEN** показано сообщение с повтором; при 401 перепроверяется сессия

### Requirement: Скачивание
Frontend SHALL скачивать файл через хук RTK Query, не сохранять его содержимое в Redux, логах или постоянном браузерном хранилище и не обращаться к произвольным URL из ответа API.

#### Scenario: Текущий файл
- **WHEN** пользователь нажимает скачать и сервер возвращает файл
- **THEN** браузеру передаётся .conf с безопасным именем, временный URL освобождается

#### Scenario: Файл недоступен
- **WHEN** download_available=false либо сервер вернул 404
- **THEN** скачивание недоступно либо показано сообщение с обновлением списка

#### Scenario: Ошибочный ответ
- **WHEN** вместо файла возвращены ошибка, пустое содержимое или неверный MIME
- **THEN** файл не создаётся и видна ошибка
