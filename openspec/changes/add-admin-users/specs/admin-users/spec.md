# Spec Delta

## Purpose
Предоставить администратору адаптивную таблицу вошедших пользователей с данными существующего серверного каталога и контролем доступа.

## ADDED Requirements

### Requirement: Доступ администратора
Frontend SHALL показывать пункт «Пользователи» только admin и закрывать страницу для обычного пользователя.

#### Scenario: Admin
- **WHEN** профиль содержит роль admin
- **THEN** в шапке и мобильном меню доступен переход к каталогу

#### Scenario: Обычный пользователь
- **WHEN** user напрямую открывает страницу каталога
- **THEN** видит отказ, запрос каталога не выполняется

### Requirement: Таблица каталога
Страница SHALL получать данные через хук RTK Query, отображать ID, имя и роль в таблице с пагинацией и поддерживать мобильные и desktop-экраны.

#### Scenario: Успешная загрузка
- **WHEN** GET /admin/users возвращает корректный массив
- **THEN** строки таблицы соответствуют ответу, доступны переходы между страницами

#### Scenario: Пустой список
- **WHEN** сервер возвращает пустой массив
- **THEN** показано пустое состояние и возврат на предыдущую страницу, если она есть

#### Scenario: Ошибка или отзыв доступа
- **WHEN** запрос завершается сетью, 5xx, 401 или 403
- **THEN** данные не отображаются, 401 ведёт на вход, 403 показывает отказ, остальные ошибки допускают повтор

### Requirement: VPN-сводка пользователя
Интерфейс SHALL отображать полученные счётчики конфигов и трафик по направлениям, подробности конфигов и качество показаний. Отсутствующие данные MUST отличаться от измеренного нуля.

#### Scenario: Расширенный ответ
- **WHEN** API возвращает vpn с counts, configs и traffic
- **THEN** видны счётчики, общий расход, отправленные и полученные байты, а подробности раскрывают список конфигов

#### Scenario: Старый API или недоступная статистика
- **WHEN** vpn отсутствует, недоступен или содержит неизвестные показания
- **THEN** интерфейс показывает отсутствие данных без подстановки нулей

#### Scenario: Неполные или устаревшие данные
- **WHEN** traffic содержит freshness=stale либо coverage=partial/unknown
- **THEN** известные значения сопровождаются соответствующими предупреждениями
