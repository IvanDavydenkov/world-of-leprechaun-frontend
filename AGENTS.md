# Правила проекта

Цель: frontend личного кабинета VPN на домене `worldofleprechauns.ru`
для доступа пользователя к своим конфигурациям и их загрузки.

Перед изменениями читать `openspec/config.yaml`: там зафиксированы целевой стек,
правила FSD, ограничения безопасности и требования к проверкам.
Новые возможности и архитектурные изменения описывать через OpenSpec:
proposal → design/specs → tasks → implementation → validation → archive.
Не представлять запланированные зависимости и возможности как уже реализованные.

Все создаваемые файлы и папки проекта называть в `kebab-case`: строчные
латинские буквы, цифры и дефисы между словами (`home-page.tsx`,
`app-providers.tsx`, `user-profile/`). PascalCase и camelCase в путях запрещены,
включая файлы React-компонентов. Суффиксы разделяются точками: `app.test.tsx`.
При переименовании обновлять импорты и ссылки с точным совпадением регистра.
Исключения — стандартные имена, обязательные для инструментов и соглашений:
`AGENTS.md`, `README.md`, `SKILL.md`, dotfiles и имена сторонних/генерируемых файлов.
Имена компонентов, функций, переменных и типов внутри кода это правило не меняет.

Интерфейс разрабатывать по принципу mobile-first: сначала компоновка и сценарии
для мобильных телефонов, затем адаптация для планшетов и компьютеров.
На больших экранах интерфейс должен оставаться удобным и визуально аккуратным:
адаптировать сетку, отступы и ширину контента. Использовать responsive-возможности
MUI и breakpoints темы. Обеспечивать читаемость, удобные области нажатия и отсутствие
горизонтального скролла страницы. При изменении UI проверять мобильный и desktop-размеры.

Обычному пользователю навигация и бургер в шапке не нужны: показывать бренд и выход.
Дополнительное меню страниц доступно только admin. Якорные ссылки на разделы
главной в навбар не добавлять; сохранять доступность выхода на мобильных экранах.

Основа приложения использует Vite/Vitest, Redux Toolkit, React Router и тему MUI.
Авторизация использует Яндекс OAuth и HttpOnly-сессию users API. Профиль и выход
подключены через RTK Query; Zod проверяет контракт профиля.
Все API-запросы интерфейса выполнять через хуки RTK Query; не использовать
прямой fetch/axios или запросы из useEffect. OAuth запускается навигацией браузера
на `/auth/yandex/login`. Секреты и токены доступны только backend.
Проверки: `npm run typecheck`, `npm test`, `npm run build`.

Production упакован в Docker: `dockerfile`, `compose.yaml`, `docker/nginx.conf`.
Проверять изменения упаковки через `docker compose config` и, при доступном Docker,
сборку образа, healthcheck, SPA fallback и 404 отсутствующих assets.

Интерфейс использует локально подключённый Roboto. Карточки имеют умеренное
скругление (12px). Текст и размеры кнопок не должны скакать при загрузке:
для скачивания сохранять подпись «Скачать» и стабильную ширину во всех состояниях.
